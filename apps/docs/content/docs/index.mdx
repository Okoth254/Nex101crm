NEX101 Hub is an open-source CRM built on Next.js, Prisma and PostgreSQL. Besides the usual CRM modules (accounts, contacts, leads, opportunities, contracts, products, tasks), it includes projects, invoices, documents, email and calendar sync, reports, AI enrichment, semantic search and an MCP server so AI agents can work with your CRM data.

You can run it yourself with Docker. The source code is in the [NEX101 Hub repository](https://github.com/Okoth254/Nex101crm).
